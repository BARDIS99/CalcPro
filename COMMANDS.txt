                    CalcPro - Command Reference
═══════════════════════════════════════════════════════════════════

📍 Navigate to project:
───────────────────────────────────────────────────────────────────
cd /home/speaker/Downloads/calcpro

🔐 Authenticate with GitHub (one-time):
───────────────────────────────────────────────────────────────────
gh auth login

    Follow prompts:
    → Choose: GitHub.com
    → Protocol: HTTPS  
    → Authenticate: Login with a web browser
    → Copy code, press Enter, paste in browser

🚀 Create repository and push (all-in-one):
───────────────────────────────────────────────────────────────────
gh repo create calcpro --public --source=. --remote=origin --push

    This creates the repo AND pushes all code!

🌐 View repository online:
───────────────────────────────────────────────────────────────────
gh repo view --web

📊 Check status:
───────────────────────────────────────────────────────────────────
git status
git log --oneline

💻 Run locally:
───────────────────────────────────────────────────────────────────
npm run dev
# Opens at http://localhost:3000
