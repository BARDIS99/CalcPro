# CalcPro

Modern dark calculator with gold accents and calculation history.

## Features
- Clean dark UI matching premium design
- Basic operations: +, −, ×, ÷
- Percentage, sign toggle, clear
- Live expression display
- Calculation history (saved in localStorage)
- Responsive: side panel on desktop, slide-in on mobile

## How to run
Open `index.html` in any modern browser.

## Files
- `index.html` – structure
- `style.css` – styles
- `script.js` – logic
