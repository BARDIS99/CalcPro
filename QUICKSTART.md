# CalcPro - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### Step 1: Launch the App
```bash
cd calcpro
npm install
npm run dev
```
Open your browser to: **http://localhost:3000**

---

## 🎮 Try These Features Right Away!

### 1️⃣ Basic Calculation (10 seconds)
1. Click: `5` `+` `3` `=`
2. See result: `8`
3. Click history button 🕑 to see your calculation saved

### 2️⃣ Earn Your First Tokens (10 seconds)
1. Click the **🪙 token button** in header
2. Click **"📺 Watch Ad (+10 🪙)"**
3. Wait 5 seconds
4. Click **"✓ Claim 10 Tokens"**
5. You now have **10 tokens**! 🎉

### 3️⃣ Save a Memory with Mood (15 seconds)
1. Calculate something: `100` `×` `12` `=`
2. Click **MS** button (Memory Save)
3. Type a name: "Monthly Budget"
4. Select a mood: 💰 Budget
5. Click **"Save Memory"**
6. Your memory is saved! View it anytime by clicking 💾 Saved

### 4️⃣ Use Advanced Math (10 seconds)
1. Click **"Advanced"** mode toggle
2. Type: `25`
3. Click **√** (square root)
4. Result: `5`
5. Try: `5` then **x²** = `25`

### 5️⃣ Convert Currency (15 seconds)
1. Calculate: `1000`
2. Click **💱 Convert** tab
3. Amount auto-fills with `1000`
4. Select: From **USD** → To **EUR**
5. Click **"Convert"**
6. See result in euros!

## 🆘 Troubleshooting

### Calculator not working?
- Refresh the page (F5)
- Clear browser cache
- Check browser console for errors

### Tokens not saving?
- Check if localStorage is enabled
- Don't use private/incognito mode
- Check browser storage settings

### Can't unlock moods?
- Make sure you have 10+ tokens
- Click the locked mood in token modal
- Watch more ads to earn tokens

### Share not working?
- Share API only works on HTTPS or localhost
- Use Copy button as fallback
- Try on mobile device for native share
